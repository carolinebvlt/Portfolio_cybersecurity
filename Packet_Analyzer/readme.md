# Packet Analyzer
My goal is not to reinvent Wireshark, but to create my own packet analysis tool, for the purpose of learning about networks and practicing Python.

## V1.0
From a PCAP file, my tool must be able to answer these questions:

- Number of packets
- Protocols used (and how many times)
- Top source IP
- Top destination IP
- Most used ports
- Number of TCP conversations
- Number of DNS requests
- Number of HTTP requests
